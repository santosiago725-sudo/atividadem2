API RESTful para gerenciamento de tarefas, construída com Node.js, Express, Sequelize e SQLite.

Funcionalidades

- Criar tarefa
- Listar todas as tarefas
- Buscar tarefa por ID
- Atualizar tarefa
- Atualizar status da tarefa
- Deletar tarefa

🛠️ Tecnologias

- Node.js
- Express
- Sequelize ORM
- SQLite
- Dotenv

▶️ Como rodar

```bash
npm install
npm run dev
